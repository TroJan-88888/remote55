[1] ภาพรวมสถาปัตยกรรมเครือข่ายจำลองชีวภาพและ IoT
==================================================================================================
ระบบคุณโชดได้รับการออกแบบโครงสร้างแบบโมดูลาร์ (Modular Architecture) ทำงานร่วมกันอย่างไร้รอยต่อผ่าน 3 ไฟล์:
1. แกนหลัก (AIMr-Chod.js):
   - ทำหน้าที่เปิดวิดเจ็ตหน้าเว็บหลัก ควบคุม HTTP Request สำหรับรีเลย์ 6 ช่อง
   - บันทึกพิกัด URL สวิตช์และตารางเวลาลง LocalStorage
   - มีระบบวิเคราะห์คำสั่ง (Intent Parser) และสังเคราะห์เสียงพูดภาษาไทย (Speech Engine)
2. โมดูลเชื่อมต่อ Telegram (Telegram Integration Module.js):
   - เชื่อมต่อบอทเทเลแกรมเพื่อสลับการสั่งงานระยะไกล (Asynchronous Long Polling)
   - ปรับปรุงสีปุ่มกดสวิตช์ในห้องแชทให้ซิงค์ตรงกับหน้าจอเว็บหลักตลอดเวลา
3. โมดูลสารบัญอัจฉริยะ (Table of Contents.js):
   - แผงควบคุมคู่มือซ้อนขนาน (Cyberpunk Overlay) ทำงานอย่างเป็นเอกเทศไม่แตะต้องโค้ดไฟล์หลัก
   - ควบคุมการเข้าถึงหน้าคู่มือสารบัญผ่านสัญญาณปุ่มกดคีย์บอร์ดอย่างเสถียร

[2] ขั้นตอนการติดตั้งและเปิดใช้งานสคริปต์ครั้งแรก
==================================================================================================
เจ้านายสามารถนำสคริปต์ทั้ง 3 ไฟล์ไปรันใช้งานได้ผ่านวิธีดังต่อไปนี้:
1. การใช้งานผ่าน Console ของบราวเซอร์:
   - เปิดหน้าต่างเว็บควบคุมที่ต้องการขึ้นมา
   - กดปุ่ม F12 บนแป้นพิมพ์ -> เลือกแท็บ Console (คอนโซล)
   - คัดลอกโค้ดทั้ง 3 ไฟล์ไปวางและกด Enter เพื่อรันทีละไฟล์ตามลำดับ
2. การรันอย่างถาวรผ่านบราวเซอร์ส่วนขยาย (UserScript):
   - ติดตั้งโปรแกรมจำพวก Tampermonkey หรือ Violentmonkey ลงบนบราวเซอร์
   - กดเพิ่มสคริปต์ใหม่ (Create a new script) แล้ววางโค้ดลงไปรันร่วมกันแบบถาวร

[3] คู่มือการควบคุมผ่านแผงเว็บหลัก (Core Web UI Dashboard)
==================================================================================================
เมื่อโค้ดแกนหลักทำงาน จะมีหน้าต่างคอนโซลจำลองสีนีออนปรากฏขึ้นที่มุมขวาล่างของบราวเซอร์:
1. ระบบสถานะระบบจำลอง (SYSTEM STATUS):
   - ไฟดวงสีเขียวกระพริบแจ้งสัญญาน Online ของปัญญาประดิษฐ์และสมองสังเคราะห์จำลอง ChodBrain
2. ข้อมูลการสั่งงานบอร์ดจริง (SMART HOME DEVICE):
   - แสดงรายการอุปกรณ์ Relay 01 - 06 ที่กำหนดค่าไว้จากโรงงาน (ค่าเริ่มต้น):
     - R1: ไฟหน้าคอม | R2: น้ำบ่อปลา | R3: จะสวดมนต์ | R4: อุปกรณ์เสริม | R5: ระบบไฟสวน | R6: เครื่องกรองน้ำ
   - คลิกปุ่ม badge [ ON ] หรือ [ OFF ] เพื่อสั่งสลับสถานะและส่งสัญญานไฟตรงไปยังบอร์ด IoT ผ่านคำขอ HTTP
3. หน้าจอบันทึกการกระทำ (COMMAND LOG):
   - แสดงประวัติการสั่งงานด้วยเสียงและการตอบสนองของบัตเลอร์อย่างแม่นยำและเรียลไทม์
4. ระบบการขยับย้ายบอร์ด (Draggable UI):
   - คลิกเมาส์ซ้ายค้าง หรือใช้นิ้วแตะสัมผัส (ทัชสกรีนบนมือถือ) ที่แถบพาดหัวสีนีออน แล้วขยับย้ายแผงควบคุมไปวางหลบในทิศทางที่ต้องการได้อย่างอิสระสูงสุด (ได้รับการแก้ไขบัคให้คลิกลากผ่านชื่อพาดหัวและตัวการ์ตูนอิโมจิ 🤖 ได้อย่างสะดวก)
5. ปุ่มควบคุมด่วน (Footer Actions):
   - 🎙️ [พูด] : กระตุ้นระบบสแตนด์บายเพื่อตรวจจับและถอดรหัสสัญญาณเสียงพูดภาษาไทย
   - ⌨️ [พิมพ์] : โฟกัสเคอร์เซอร์ป้อนคำสั่งพิมพ์คำสั่งผ่านคีย์บอร์ดลงบนกล่อง input ทันที
   - ⚙️ [ตั้งค่า] : เปิดแผงแก้ไขชื่ออุปกรณ์ ลิงก์ URL สั่งเปิด และลิงก์ URL สั่งปิด ทั้ง 6 ช่อง โดยตัวแผงหน้าต่างจะขยายความกว้างแบบ จอใหญ่ (Large) อัตโนมัติเพื่อให้กรอกลิงก์สะดวกสบาย

[4] คู่มือการควบคุมระยะไกลผ่าน Telegram Bot (Telegram Integration)
==================================================================================================
แผงขนาดเล็ก "Telegram Config" จะปรากฏขึ้นเคียงข้างวิดเจ็ตแกนหลักเพื่อทำหน้าที่เชื่อมต่อบอท:
1. วิธีผูกรหัสตั้งค่า:
   - นำ HTTP API Token ที่ได้จาก @BotFather และ Chat ID ประจำตัว มากรอกใส่ช่อง แล้วกด "บันทึกและเชื่อมต่อ"
   - ตัวแผงจะส่งรีโมตคีย์บอร์ดเรืองแสงเข้าไปยังห้องแชทของคุณใน Telegram ทันที และจะย่อขนาดเก็บลงมุมจอ
   - แผงนี้ได้รับการอัปเกรดให้รองรับระบบสัมผัส (Touch Drag) บน Telegram Web App มือถือเรียบร้อยแล้ว
2. การคุมอุปกรณ์ผ่านคีย์บอร์ดเรืองแสง (Inline Panel Keyboard):
   - แสดงปุ่ม R1 - R6 พ่วงชื่ออุปกรณ์ โดยมีไฟบอกสถานะ 🟢 ON และ 🔴 OFF ซิงค์ตรงกับหน้าจอคอมพิวเตอร์จริง
   - ปุ่มกระตุ้นสารเคมีจำลอง (Caffeine คึกคัก / Sedative สงบ / Psychedelic หลอน / Reset สมอง)
   - ปุ่มรายงานดัชนีตรวจวัดประสาทและสถานะ IoT ปัจจุบัน
   - ปุ่มส่งแผงรีโมตควบคุมตัวใหม่เข้าไปในห้องแชทในกรณีที่ข้อความแชทอื่นดันรีโมตหายไปแล้ว
3. การส่งสัญญาณแชททั่วไป:
   - เจ้านายสามารถพิมพ์หรือคุยปกติกับบอท เพื่อส่งประโยคคำสั่งข้ามเครือข่ายเข้ามาสั่งงานตัวเว็บหลักที่บ้าน และสังเคราะห์เสียงพูดโต้ตอบในบ้านได้จากระยะไกล

[5] ระบบวิเคราะห์เวลาและล้างข้อมูลขยะอัตโนมัติ (Automated Schedule Heuristics)
==================================================================================================
ระบบได้รับการแก้ไขบัคและปรับใช้กลไกการสืบค้น Heuristic เพื่อป้องกันข้อผิดพลาดเวลาปลอมดังนี้:
1. การกั้นพิกัด IP (Digit Boundary Matcher):
   - ตัววิเคราะห์เวลาใช้ Regex กั้นพิกัดหลัก `(?<!\d)[0-2]?\d[:.][0-5]\d(?!\d)` ทำให้สกัดเฉพาะเวลาจริง เช่น 09.30 หรือ 18.00 โดยละเว้นกลุ่มตัวเลข IP Address เช่น `.1.18` (จาก `192.168.1.189`) ทิ้งไปอย่างปลอดภัย
2. ท่อกรองขยะคำค้นหา (Sanitization Pipeline):
   - สคริปต์รับข้อความจะทำการแยกกวาดล้างลิงก์ URL (`http/https`) ออกจากคำสัญญาน และตัดอักขระพิเศษวรรคตอนนอกระบบ จนเหลือเพียงชื่อกลางคีย์เวิร์ดของอุปกรณ์ที่ชัดเจนสูงสุด
3. ตัวอย่างการสั่งตั้งเวลาและผลลัพธ์ผ่าน Telegram:
   - เจ้านายพิมพ์: "ตั้งเวลาน้ำบ่อปลา เปิดเวลา 09.30 ปิดเวลา 18.00.http://192.168.1.189/RELAY=OFF"
   - บอทประมวลผลและตอบกลับ:
     🤖 AI : ✅ ตั้งตารางเวลาสำหรับ *น้ำบ่อปลา* (Relay 02) สำเร็จแล้วครับเจ้านาย:
       └─ 🟢 เปิดทำงาน: *09:30*
       └─ 🔴 ปิดทำงาน: *18:00*
4. ตัวอย่างการพิมพ์ยกเลิกเวลา:
   - พิมพ์: "ยกเลิกตั้งเวลา น้ำบ่อปลา" หรือ "ปิดตารางเวลา ไฟหน้าคอม"
   - บอทประมวลผลตอบกลับ: ✅ ยกเลิกการตั้งเวลาของ *น้ำบ่อปลา* เรียบร้อยแล้วครับเจ้านาย

[6] พจนานุกรมคำสั่งเสียงและการจำบริบทสนทนา (Stateful Intent Parser Reference)
==================================================================================================
เมื่อทำการสั่งการด้วยคำพูดใส่ไมโครโฟนหน้าเว็บ หรือพิมพ์ผ่านอินพุต ระบบจะเทียบตรรกะประมวลคำสั่งดังนี้:

>> [ คำสั่งพิเศษและระบบลับ ]
1. "Trojan"
   - ความหมาย: คำสั่งกวาดล้างไฟล์ขยะและลบหน่วยความจำทั้งหมดของโปรแกรมออกถาวร (Factory Reset)
   - การทำงาน: ล้าง Config รีเลย์, ล้างคีย์เทเลแกรม จากนั้นบัตเลอร์จะอธิบายรายละเอียดขั้นตอนการทำความสะอาดระบบจนจบ และสั่ง reboot โหลดหน้าต่างเว็บใหม่โดยอัตโนมัติหลังหน่วงเวลา 7.5 วินาที
2. "บัง"
   - การทำงาน: ซ่อนแผงกรอกโทเค็น Telegram (tg-config-panel) ออกจากหน้าต่างเบราว์เซอร์
3. "แสดงเทเลแกรม" หรือ "โชว์เทเลแกรม" หรือ "เปิดเทเลแกรม"
   - การทำงาน: นำแผงควบคุมตั้งรหัส Telegram กลับขึ้นมาแสดงผลตามปกติ
4. "จะตั้งเวลา" หรือ "ตารางเวลา" หรือ "เปิดตั้งเวลา" (เกี่ยวกับเวลา)
   - การทำงาน: เปิดหน้าต่างกำหนดเวลาเปิดปิด 24 ชั่วโมงขนาดใหญ่ออกมากึ่งกลางหน้าต่างจอภาพ
5. "จะเพิ่ม" หรือ "ตั้งค่า" หรือ "เปิดตั้งค่า" (เกี่ยวกับคอมฟิก)
   - การทำงาน: ขยายขนาดวิดเจ็ตหลักเป็นจอภาพขนาดใหญ่ (large) เพื่อให้ป้อน URL บอร์ดสวิตช์ได้ง่าย
6. "ย้ายไปหน้าสอง" หรือ "หน้าสอง" หรือ "จอสอง"
   - การทำงาน: ส่งสัญญานจำลองการคลิกเปลี่ยนจอ Deck 02 บนอินเตอร์เฟสส่วนกลางปลายทาง

>> [ คำสั่งระบบสวิตช์บอร์ด ]
1. "เปิดทั้งหมด" / "เปิดระบบทั้งหมด" -> สั่งเปิด Relay 1-6 พร้อมกันทั้งหมดทันที
2. "ปิดทั้งหมด" / "ปิดระบบทั้งหมด" -> สั่งปิด Relay 1-6 พร้อมกันทั้งหมดทันที
3. "เปิด [ชื่ออุปกรณ์]" -> สั่งการเปิดเฉพาะบอร์ดนั้นๆ (เช่น "เปิดน้ำบ่อปลา")
4. "ปิด [ชื่ออุปกรณ์]" -> สั่งการปิดเฉพาะบอร์ดนั้นๆ (เช่น "ปิดไฟหน้าคอม")

>> [ ระบบจดจำบริบทสนทนาย้อนกลับ (Stateful Context Window) ]
- เมื่อเจ้านายพูดเฉพาะชื่ออุปกรณ์โดยไม่มีคำกริยา เช่น พูดคำว่า "น้ำบ่อปลา" หรือ "ไฟหน้าคอม"
- ตัวประมวลผล Intent Parser จะจำว่าเจ้านายกำลังเพ่งความสนใจไปที่อุปกรณ์ใด และถามกลับทันทีว่า:
  🤖 AI : "ตรวจพบชื่อระบบ น้ำบ่อปลา เจ้านายต้องการให้กระผมเปิดหรือปิดการทำงานดีครับเจ้านาย"
- ภายในเวลา 20 วินาที เจ้านายสามารถตอบกลับบัตเลอร์ด้วยภาษาพูดทั่วไปได้ทันที เช่น:
  - พูดตอบกลับ: "ใช่" / "ตกลง" / "เปิด" / "on" -> ระบบจะสั่งเปิดอุปกรณ์และล้างหน่วยความจำสนทนาทันที
  - พูดตอบกลับ: "ไม่ใช่" / "ยกเลิก" / "ปิด" / "off" -> ระบบจะสั่งปิดอุปกรณ์และล้างหน่วยความจำสนทนาทันที
- หากเกิน 20 วินาทีไม่มีสัญญาณโต้ตอบ ระบบจะทำความสะอาดลบหน่วยความจำสนทนานั้นทิ้งเพื่อความเสถียร


==================================================================================================
[7] ระบบปุ่มคีย์ลัดด่วนของโปรแกรม (Keyboard Shortcut Reference)
==================================================================================================
เพื่อเพิ่มประสิทธิภาพและความรวดเร็วในการตรวจสอบข้อมูลคำสั่ง สารบัญอัจฉริยะได้รับการกำหนดค่าปุ่มลัดแป้นพิมพ์:

>> สัญลักษณ์ปุ่ม: [ T ] หรือ [ t ]
- ประโยชน์: กดสั่งแสดง หรือสั่งปิดพับหน้าต่างคู่มือและแผนผังพจนานุกรมเล่มใหญ่นี้กึ่งกลางจอทันที
